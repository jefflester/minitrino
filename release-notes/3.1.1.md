# Minitrino Release Notes: 3.1.1

## Release Overview

Minitrino 3.1.1 is a patch release that restores the `minio` module after the
upstream `minio/minio` and `minio/mc` images were removed from Docker Hub.

**Key improvements:**

- Switched the `minio` module to the community-maintained `pgsty/minio` and
  `pgsty/mc` images

**Table of Contents:**

- [Library Changes and Additions](#library-changes-and-additions)

## Library Changes and Additions

### Bug Fix: MinIO Images Removed from Docker Hub

MinIO has stopped distributing community images, and both `minio/minio` and
`minio/mc` are no longer available on Docker Hub. As a result, provisioning the
`minio` module (and every module that depends on it, including `hive`,
`iceberg`, `iceberg-hms`, `delta-lake`, `spooling-protocol`, and
`results-cache`) failed with an image pull error.

**The fix:**

- The `minio` service now uses `pgsty/minio`, and the `minio-client` service
  now uses `pgsty/mc`. These are drop-in, multi-arch (amd64/arm64) forks of the
  upstream images.
- Updated version pins in `minitrino.env`:
  - `MINIO_VER`: `RELEASE.2025-05-24T17-08-30Z` → `RELEASE.2026-08-04T00-00-00Z`
  - `MINIO_MC_VER`: `RELEASE.2025-05-21T01-59-54Z` →
    `RELEASE.2026-09-16T00-00-00Z`

Users who override `MINIO_VER` or `MINIO_MC_VER` must use a tag published under
the `pgsty/minio` and `pgsty/mc` repositories.
